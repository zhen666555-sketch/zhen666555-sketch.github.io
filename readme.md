# 曹泽祯 · ZHEN

原生 HTML / CSS / JavaScript 个人主页，采用「深空指挥舱」视觉。内容依据个人经历库整理，包含两段实习与七项项目。

## 本地查看

直接使用浏览器打开 `index.html` 即可。页面不依赖构建工具、外部字体、CDN 或在线接口，项目展开与动态场景均可离线使用。

## 页面与素材

- `index.html`：个人介绍、项目档案、工作经历、技术领域及联系入口，正文为静态 HTML。
- `assets/site.css`：响应式布局、星云氛围、光线与界面动画。
- `assets/site.js`：Canvas 三维网络球、五层轨道光点、星场、流星、鼠标视差、手机导航和动效开关。
- `assets/*.webp`：通过内置 image_gen 生成的背景与项目概念视觉，使用压缩副本；项目图不代表实际界面或实拍。
- `design/index.html`：最初三套方案对比。
- `design/portfolio-content.json`：核验后的内容草稿和编辑说明，修改它不会自动重建正式首页。
- `design/design-directions.json`、`design/production-assets.json`：设计方向与完整生图提示词。

## 动态效果

桌面场景最高按约 45 帧/秒绘制；窄屏降低为约 30 帧/秒，并减少点云及星星数量。实际帧率取决于设备，不作为性能保证。页面进入后台时停止绘制，主球离开可视区域时停止绘制主球。

页脚可暂停或恢复动态效果，选择保存在当前浏览器。首次访问遵循系统 `prefers-reduced-motion` 设置。所有正文、导航和项目内容独立于动画可用。
